Managing Commands

This page lists available commands used to manage your channels on JamsTube. Each command is described with its usage and examples.

Rules for Adding

  • You're can have unlimited sub-channels. But you'll wait 4 more days to add another ones.
  • AVOID INAPPORATIVE CONTENT, INVAILD FROM ADDING IF THERE WAS!
Add User Command
Allows users to add themselves to the leaderboard.
Example: !add Example example.com/example.png — Add user named Example with profile picture example.com/example.png
Command:
!add
Name: Example
Profile Picture: example.com/link/to/your/pfp.png
Country: United Kingdom (optional)
Content type: Vlog (optional)

Use this command to register a user on the leaderboard. Provide the name and an image URL; country and content type are optional.

Change Channel Name Command
Use this command to rename your channel to something different.
Example: !change name Example2 — Change channel name from Example to Example2
Command:
!change name NewName

Fact: Your new name can affect your channel growth! They might gonna be with you if your new name is cool!

Change Channel Profile Picture Command
Use this command to update your channel's profile picture.
Example: !change pfp new-profile-picture.png — Update channel profile picture to new-profile-picture.png
Command:
!change pfp ImageURL

Fact: This command can be used along with !change name:
!change name.pfp NewName ImageURL
As of always, URL link is not forced and you can simply upload the image.

Merge Channels Command (ONLY IF YOU HAVE SUB-CHANNELS)
Merge 2 of your channels into one.
Example: !merge Example1 Example2 — Merge Example1 and Example2 into Example1
Command:
!merge ChannelMergeInto ChannelDeleteAfterMerge

MERGING CHANNELS DOESN'T MEAN ADD ALL IN ONE LIKE 41293+3912, IT'S ONLY MERGE PART OF THEM (Ex: Even Channel2 has 3912 Subs, after merge just adds 2314 of them). For balancing reasons.

Delete Channel (DANGEROUS)
Permanently delete a channel and all its associated data.
Example: !delete Example — Delete the Example channel permanently
Command:
!delete / !del (short form) ChannelName

DANGEROUS — This command will permanently delete the specified channel and all its data!
If you doesn't have sub-channels, Channel Name is not necessary.
